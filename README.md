## :dart: O guia para alavancar a sua carreira

> Scala roda sobre a JVM e combina orientação a objetos com programação funcional num único sistema de tipos — é a linguagem por trás do Apache Spark, do Akka/Apache Pekko e de boa parte da infraestrutura de dados e de sistemas distribuídos de alta escala no mercado. Este guia reúne documentação oficial, cursos, livros, ferramentas do ecossistema (sbt, Scala CLI, Metals, ZIO, Cats) e um capítulo dedicado a usar IA na prática com Scala — tudo verificado e organizado para quem já programa e quer entender por que bancos, fintechs e times de engenharia de dados escolhem Scala para os sistemas mais críticos.

## 🗺️ Roadmap

> Scala não tem um roadmap visual oficial como outras linguagens, mas o próprio time que mantém a linguagem (Scala Center, na EPFL) publica um caminho de aprendizado reconhecido: entenda por que o Scala 3 existe, leia o livro oficial do zero ao avançado e, se quiser uma trilha estruturada com certificado, siga a especialização criada por Martin Odersky (criador da linguagem) no Coursera.

- [Scala 3 Book — Why Scala 3?](https://docs.scala-lang.org/scala3/book/why-scala-3.html) — Explica as motivações e mudanças do Scala 3 em relação ao Scala 2, o melhor ponto de partida conceitual.
- [Scala 3 Book — sumário completo](https://docs.scala-lang.org/scala3/book/introduction.html) — Índice do livro oficial: da sintaxe básica a tipos avançados, na ordem recomendada de estudo.
- [Functional Programming in Scala Specialization (Coursera)](https://www.coursera.org/specializations/scala) — Trilha oficial da EPFL em 5 cursos, do básico a sistemas distribuídos com Spark.

## 🚀 Por onde começar

> Uma trilha prática para sair do zero e escrever seu primeiro programa Scala 3 sem se perder em configuração.

- [Instale o Scala CLI](https://scala-cli.virtuslab.org/) — Ferramenta oficial para rodar, compilar e empacotar Scala com um único binário, sem configurar projeto.
- [Scala 3 Book — Taste of Scala: Hello World](https://docs.scala-lang.org/scala3/book/taste-hello-world.html) — Seu primeiro programa, explicado linha a linha.
- [Scala 3 Book — A Taste of Scala](https://docs.scala-lang.org/scala3/book/taste-intro.html) — Um apanhado rápido de classes, funções, coleções e concorrência antes de ir a fundo em cada tópico.
- [Scala 3 Book — Scala Features](https://docs.scala-lang.org/scala3/book/scala-features.html) — Visão geral das características que diferenciam Scala de Java e de linguagens puramente funcionais.
- [Scala Toolkit — Introdução](https://docs.scala-lang.org/toolkit/introduction.html) — Conjunto de bibliotecas oficiais para tarefas do dia a dia (HTTP, JSON, arquivos, testes) sem precisar escolher entre dezenas de libs concorrentes.
- [A Tour of Scala](https://docs.scala-lang.org/tour/tour-of-scala.html) — Tour interativo pelos principais conceitos da linguagem, oficial e direto ao ponto.

## 🤖 IA na prática

Scala tem um sistema de tipos rico — variância, `given`/`using`, tipos de efeito como os do ZIO e do Cats Effect — que funciona como um segundo revisor sempre que uma IA gera código para você. Use isso a seu favor.

**Para aprender**
- Cole um erro do compilador (ex.: `Found: Int, Required: String` ou um erro de resolução de `given`) e peça: *"explique a causa e mostre como corrigir sem esconder o problema com `asInstanceOf`"*.
- Peça para **reescrever um loop imperativo com `var`** usando `foldLeft`, `map` ou `for-comprehension`, e explicar cada passo.
- Peça uma explicação linha a linha de um `for-comprehension` sobre `Option`/`Either`/`IO`, e depois teste no [Scastie](https://scastie.scala-lang.org/) para confirmar o comportamento.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (case classes, pattern matching, type classes, `given` instances).
- Peça para gerar propriedades de teste com ScalaCheck para uma função pura que você acabou de escrever.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para: migrar trechos de Java para Scala incrementalmente, gerar boilerplate de jobs Spark, escrever endpoints Tapir e gerar testes com ScalaTest/munit.
- Depois de **cada** sugestão aceita, rode `sbt compile` (ou `scala-cli compile`) e o `scalafmt`/`scalafix`. Se o código só compila com `.asInstanceOf`, `.get` sem checagem ou `@unchecked`, a sugestão provavelmente está errada.
- Ao trabalhar com Akka/Pekko, confirme sempre qual dos dois a IA está sugerindo — muitos modelos ainda misturam exemplos do Akka (agora com licença comercial acima de certo faturamento) com o Apache Pekko (fork 100% open source).

**Limites e boas práticas**
- IA **inventa combinadores** de Cats/ZIO e assinaturas de métodos do Spark que não existem em versões recentes. Confirme sempre no Scaladoc oficial da biblioteca antes de usar.
- Ela tende a sugerir `Future` e efeitos colaterais soltos onde um tipo de efeito (`IO`, `ZIO`, `Task`) resolveria o problema de forma mais segura — prefira o tipo mais explícito.
- Não cole código proprietário, segredos ou dados de clientes em ferramentas sem a política da sua empresa — muito comum em times de dados que lidam com informação sensível via Spark.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

**Bibliotecas Scala-first para trabalhar com LLMs**
- [sttp-ai](https://github.com/softwaremill/sttp-ai) — Toolkit Scala para consumir OpenAI, Claude e outros provedores compatíveis, com tipos fortes.
- [openai-scala-client](https://github.com/cequence-io/openai-scala-client) — Cliente Scala para a API da OpenAI e outros grandes provedores de LLM.
- [zio-openai](https://github.com/zio/zio-openai) — Cliente para a API da OpenAI construído sobre ZIO.
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; gratuito para estudantes e com plano free.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA integrada ao fluxo de trabalho.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: refatora, escreve testes e explica tipos complexos em Scala.

## 🎓 Certificações

Não existe uma certificação oficial de Scala mantida pela Scala Center. O mercado valoriza projetos publicados e experiência prática com o ecossistema (sbt, Spark, Akka/Pekko) mais do que certificados. As opções abaixo emitem certificado de conclusão do curso, não uma certificação da linguagem em si.
